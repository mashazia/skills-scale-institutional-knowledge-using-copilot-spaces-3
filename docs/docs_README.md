# OctoAcme Project Management Docs

Welcome to the OctoAcme project management process documentation. This README serves as an entry-point to all our key process docs, helping you understand how we run projects, make decisions, manage risks, and drive continuous improvement.

## Overview: Project Management Processes at OctoAcme

Our approach prioritizes customer value, iterative delivery, and clear accountability. We use a lightweight, evidence-driven project management cycle:

### The OctoAcme Project Lifecycle

1. **Initiation:** Define the problem, stakeholders, success criteria, and a high-level timeline
2. **Planning:** Break work into actionable increments, estimate effort, identify risks, and plan releases
3. **Execution & Tracking:** Run daily standups and weekly syncs, manage work via project boards, follow PR/testing conventions, and escalate blockers
4. **Risk Management & Communication:** Maintain a risk register, provide regular status updates, and follow clear escalation paths
5. **Release & Deployment:** Standardized pre-release criteria, checklists, and rollback protocols
6. **Retrospective & Continuous Improvement:** Capture learnings and translate them into action items after each milestone or incident

### Key Principles

- **Customer-first:** Prioritize customer value and usability
- **Iterative delivery:** Deliver small, testable increments
- **Clear ownership:** Each project has named Project Manager (PM) and Product Lead
- **Data-informed decisions:** Measure impact and iterate based on evidence
- **Psychological safety:** Encourage feedback and learning

### Core Roles

- **Project Manager (PM):** Coordinates delivery, schedules, risk, and communications
- **Product Manager (PdM):** Defines outcomes, prioritizes backlog, and measures success
- **Developers:** Implement features, collaborate on design and testability
- **QA/Testing:** Validate quality and acceptance criteria
- **Stakeholders:** Provide inputs and approvals

## Getting Started

**For New Team Members:**
1. Read the [Project Management Overview](./octoacme-project-management-overview.md) for a high-level introduction
2. Review [Roles & Personas](./octoacme-roles-and-personas.md) to understand your role and responsibilities
3. Refer to the specific process docs as you move through project phases

**For Project Managers:**
- Follow the sequence: Initiation → Planning → Execution & Tracking → Release → Retrospective
- Use the checklists in each guide to ensure nothing is missed
- Reference Risk Management & Communication throughout for escalation and reporting

**For Product Managers:**
- Start with [Project Initiation Guide](./octoacme-project-initiation.md) to validate ideas
- Use [Project Planning](./octoacme-project-planning.md) to create the backlog and success metrics
- Refer to [Execution & Tracking](./octoacme-execution-and-tracking.md) for quality and metrics management
